# v3.3.13-t9.16 — 无障碍与设备适配

本说明随发布文档冻结；在线发布状态以本版本 Release 为准。

按键、候选、九键拼音筛选和预编辑区补齐无障碍名称、角色、选中状态及操作。动态回车键随发送、搜索等动作更新名称；候选刷新后的旧操作会被身份检查拦截。改善大字体、横屏、窄屏与系统 inset 下的布局；短屏内容可滚动访问。首次设置的试打焦点与已结束输入会话的缓存读取也已修正。

当前候选 `cc2d6bd6` 的 812 项应用 JVM 测试与 227 项宿主检查新执行通过，Debug／Release Lint 无问题，构建与双 ABI Release 签名检查无警告。384 项原生检查按 31 项相同输入绑定复用历史结果，本轮没有重跑，也不声称生产 JNI 全部重新编译。

Android 5.0 四组矩阵、Android 15 八组矩阵，以及 Android 15 的 Steam 深色补测均已通过限定功能检查。Android 15 正式 APK 上，实际 TalkBack FOSS 探索与双击完成九键输入、筛选 `mi`、提交“米”和发送。常规及两倍字体下，上下两个实际分屏位置的探索、筛选和准确一次选词均通过，设置恢复与观察进程正常退出。系统夜间模式矩阵沿用浅色配色，真正深色的像素依据来自额外 Steam 补测。

Android 5.0／15 分别保留 3,865／27,115 条 W/E 记录；目标中的主题、试打焦点、关闭会话和导入等待问题本轮未复现，但不能称“所有系统警告已消除”。TalkBack FOSS 语音初始化、系统目录事件注入、图形和测试 WebView renderer 等剩余记录在验证报告中单列。没有真机验收，物理 ARM64、OEM、16 KiB 页、真实语音／TTS、候选 P95／PSS 和长期驻留仍待验证。

手动附件仅 ARM64、x86_64 两个正式 APK 与包含主仓库和 21 个递归子模块的完整源码包；GitHub 自动生成的 source zip／tar 保留。详细范围见 [9.16 验证报告](https://github.com/X2M7/trime/blob/develop/script/quality/VALIDATION-t9.16.md)。
