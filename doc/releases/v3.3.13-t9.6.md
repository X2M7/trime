# Trime v3.3.13-t9.6 / T03 Preview

## Changes

- Dictionary-backed pinyin choices with syllable locking, middle-segment editing,
  unlocking and undo. Selecting pinyin does not commit Hanzi.
- Reliable raw-input editing, cancellable repeating Backspace, and separate
  composition cancellation; no private constraint codes committed to the editor.
- Both built-in themes use a 3x3 main area with side controls and an adaptive
  pinyin list. Left/right one-handed modes and key height are configurable.
- Long-press 2-9 enters literal digits; 1 separates syllables, long-press 1
  enters a digit, and 0 always enters a literal digit. Space slides the caret.
  Swipes/long presses do not also generate an ordinary tap.
- Includes the upstream integration, SAF hardening and CMake warning fixes
  already present on this fork's develop branch. Android minSdk remains 21.

- VersionName `3.3.13-t9.6`; versionCode `20261108`.
- Package `com.osfans.trime.debug`; displayed name has no Debug suffix.
- Retains the v3.3.11-t9.4 preview certificate for in-place upgrades:
  `c6fb875b1959f56fc6b3992d603b86e2dcd793677d32aba83687b34ef6937dd2` (SHA-256).
- This is the existing debug-signed, debuggable preview variant, not a
  production-signed or R8-minified APK. Do not confuse the GitHub Release
  publication with the Gradle `release` variant or upstream's application.
- Back up configuration and dictionaries before upgrading; do not uninstall or
  clear data to upgrade. Custom copies of the T9 schema/themes may require
  merging the new rules/layout and redeploying. Do not erase personal learning.
