# Trime v3.3.13-t9.13

本轮稳定版验收通过，线上状态以[版本 Release 页面](https://github.com/X2M7/trime/releases/tag/v3.3.13-t9.13)为准。支持 Android 5.0+，提供 ARM64 与 x86_64 Release APK。

- 默认全拼与九键共享学习库。个人词库可导入、导出和备份恢复；常用短语可编辑、导入导出，修改前自动备份供恢复。Rime portable 快照导入合并记录，精确文件备份恢复替换受保护文件。
- 候选可按方案及输入置顶或恢复排序。忘词请求移除已学习记录，未学习词可能提示无法忘记；不永久屏蔽系统词，不删除置顶规则。隐私模式不应用或修改置顶。
- 支持可选横向候选滚动、拼音注释和长候选全文阅读；展开保留原来的阅读位置，刷新后的旧手势会被拒绝。失败提示可在通知权限被拒绝时显示，切换编辑器会清理旧提示。
- 支持 Shift 双击锁定并保留自定义主题动作；关闭该功能后仍按普通点击处理。

本轮 702 项新执行应用 JVM 测试、213 项新执行宿主测试通过；build-logic 17 项和 compatibility 6 项为缓存结果，单列统计。Debug／Release Lint、构建及签名警告均为 0。双 ABI Release 签名检查通过，minSdk21、versionCode20261118、DEBUG=false。

Android 5.0 和 Android 15 模拟器分别完成正式 Release 从旧9.12覆盖升级、三次便携备份、候选界面6场景7检查与常用短语2检查，并恢复原配置与输入法。另分别完成单独 Debug 两主题回归、快速输入40轮与键盘显示隐藏100次。两轮4,463／11,620条原始 W/E/F 与完整控制台诊断均保留并逐行审阅，实际驱动及模拟器正常停止。
