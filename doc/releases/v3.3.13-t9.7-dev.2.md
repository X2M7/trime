# Trime v3.3.13-t9.7-dev.2 / Runtime Preview

This is a prerelease of the already-tested build 16, not the next input-field
and lifecycle change. The previous t9.6 remains GitHub Latest.

## Changes

- T04 adds fixed Chinese ranking and learning benchmarks with pinned dictionary
  experiments. Luna remains the default; no larger dictionary or grammar model
  is enabled without a measured benefit.
- T05 separates six optional fuzzy-pinyin rules from bounded numeric-key repairs.
  All are off by default. Suggestions identify their source; selecting a pinyin
  constraint does not immediately commit Hanzi or replace the raw input.
- Repairs cover failed engine deployment/retry, JNI string and lifecycle safety,
  atomic resource installation, SAF synchronization and deletion protection,
  clipboard/collection save completion, input-connection ownership and feedback.
- Main-toolbar actions now have valid resource IDs, fixing the autofill resource
  error. Android 5.0 support is retained.

## Verification And Known Issues

- 256 application and four build-logic JVM tests, 72 host tests, strict Lint and
  Spotless pass. The complete build log has no warnings.
- Build-16 API-21/35 navigation and clipboard checks pass. SAF real-tree round
  trip, restart and revocation were verified with the unchanged SAF code in
  builds 14/15. Older results are not relabeled as build-16 tests.
- This is NOT an all-warnings-cleared release. On a two-core/2GB x86 emulator
  translating ARM64, T02 editor assertions pass but the queue watchdog fails at
  2920ms during first-theme deployment. Startup/animation slow frames remain.
- Native ARM phone performance, OEM editor coverage, physical 16KB-page devices
  and release/R8 behavior are not established by these emulator tests.
- Third-party theme fallback and the full input-field/lifecycle matrix are the
  next development work; they are not claimed as fixed by this release.
