## 本版修改

- 候选快照携带编辑器 token、单调 generation 和可选请求 ID。选词、忘词、翻页与分页读取在原 Rime 单线程中核对归属，拒绝旧结果；输入和提交继续按原队列顺序送达。
- 保留既有一次 JNI 聚合响应及构造签名；初始 bulk 候选窗口仍为 16，展开分页单次最多 48，修复已知总数时末项候选漏载。
- 日常关闭性能追踪；隔离测量构建可启用纯数值 TrimePerf，记录队列、计算、候选绘制和成功文本提交，隐私模式不采样。256 项诊断缓存淘汰不改变输入队列，也不把迟到成功提交误记取消。
- 增加现有布局/按键缓存数量统计，延续已有 TTS/SoundPool 按启用状态创建，不宣称已测出驻留改善。
- 公开 APK 改为非 debuggable Release/R8；保留 Coroutine ServiceLoader 接口、提供者及服务资源，维护 R8 后的服务发现契约。

- 恢复 AutoScaleTextView 的框架文本、测量与布局契约：文本经 super.setText 更新并执行 super.onMeasure / super.onLayout，保留候选自适应缩放。新增两个主题的 native `64` 候选 Unicode、accessibility node、软件绘制和真实屏幕字形回归；两个 API 的本轮双主题原图与像素重数通过；视觉审阅者为 Codex assistant，不是人类或 OCR。
