# Trime v3.3.13-t9.9

**Build13完整构建、宿主测试与独立静态通过；最终30组功能执行、四份独立范围审查及最终汇总裁决均通过。**

本版整合 11 项上游改动，改善第三方主题兼容、九键输入恢复、按键气泡和词典部署，保留 Android 5.0+、ARM64 与 x86_64 支持。

## 改动

- 改善第三方主题的键盘尺寸继承和按键动作解析，保留九键、回车、长按删除及滑动编辑；无效按键预设仍明确报告。
- 直接读取可支持的主题源配置；需要完整 librime 解析的主题自动重新部署，正常回退只记录说明信息，真实解析或部署失败继续报告并可重试。
- 修复配色切换后气泡和长按键盘的旧颜色残留，保留焦点和布局；恢复旧主题的气泡尺寸、字号及字体回退，随包主题使用系统预览字体。
- 修复降级键盘在大字号下的小数点消失及数字、“@”裁切，保留原按键大小。
- 修复 Android 5.0 通知状态图标依赖主题属性而触发资源警告的问题；图标形状和尺寸保持。
- 修复引擎停止或重新部署时旧提示清理任务访问新输入上下文的问题。
- 词典转换成功后再替换输出，失败保留原文件；补充格式、写入和关闭错误检查，修复损坏词典异常路径的缓冲及文件句柄释放。
- 复用内容未变的词典转换结果；源文件或输出变化时重新转换。
- 移除无运行用途的 serialization 所有权元数据，保留协程异常处理和主线程调度所需的服务。

外部日志证据处理期间出现一次超长整数序列化失败和两次未保留失败字符串的JSON读取异常；ARM正式运行前另有一次没有保留失败字节/摘要的测试APK安装摘要不匹配，根因均仍未知。当前SHA固定的数据已由Node、jq与Python各3轮解析，并按原始日志、事件ID和上下文逐项重算；ARM应用与测试APK随后各5次完整读取也一致。这个结论只覆盖当前冻结快照，不恢复失败输入，也不宣称宿主间歇问题已修复。

最终汇总选择30/30组，证据错误0项，并保留166个需要逐条裁决的critical finding；汇总返回码2是人工裁决门的预期状态，不是功能失败。最终裁决逐项覆盖166个critical ID/188次原始出现与647个项目作用域索引，四类未解决集合均为空，运行发布门通过；裁决SHA为 `717b6b1e0daa80a41bd8b1b65cd1a376d885ff7b0d4aa7b1b8abfe0d005ca463`。ARM范围审查逐项接受三组中的101条应用W/E、14条项目事件、48个critical ID和17张原图，仍明确保留平台ANR、Binder/SELinux未知调用方与原始警告。详细边界见 [T07 验证报告](https://github.com/X2M7/trime/blob/v3.3.13-t9.9/script/quality/VALIDATION-T07.md)。
