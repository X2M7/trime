# Trime v3.3.13-t9.8 / T06 稳定版

**冻结APK已通过构建、宿主及30组Android5.0/15模拟器和ARM64转译检查；运行日志已逐项裁决。**
验收限于下列范围，保留平台警告和历史失败；不宣称所有可能的缺陷或风险均已消除。

本版集中修复输入框切换、九键恢复、窗口生命周期和部署恢复，保留九键拼音、音节锁定、中间编辑、撤销，以及默认关闭的模糊音/数字键纠错。

## 修复内容

- 输入框类型与回车动作统一；从邮箱、密码、数字等输入框返回聊天框时恢复九键。
- 隔离编辑器连接的排队按键、候选、提交、主题对话框及选项回调，避免旧操作影响新输入框。
- 第三方主题缺少所需布局时回退；启动或部署失败时保留数字输入、重试及系统输入法切换入口。
- 修复 Android5.0 预编辑浮层的 BadToken 崩溃及隐藏/重新显示状态问题。
- 修复有限消息缓冲溢出可能丢失提交/按键，以及故障通知持锁造成的并发阻塞。
- 修复大字体候选注释裁切、剪贴板多行编辑内容覆盖按钮、通知权限对话框 WindowLeaked。
- 数字键盘空格键显示完整“空格”，保留原SPACE事件；构建时间改为毫秒，修复1970年显示。
