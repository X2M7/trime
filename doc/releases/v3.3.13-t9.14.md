# Trime v3.3.13-t9.14

本轮稳定版验收通过，线上发布状态以[版本 Release 页面](https://github.com/X2M7/trime/releases/tag/v3.3.13-t9.14)为准。支持 Android 5.0+，提供 ARM64 与 x86_64 Release APK，versionCode `20261119`。

- 增加默认关闭的轻量离线下一词联想，可在候选设置中开启。随附全拼、简化字及九键方案在提交汉字后显示建议；只有明确点击当前建议才提交。数字键开始新九键输入；回车、空格、删除、标点及编辑器切换取消旧联想。关闭设置、ASCII 或隐私模式停止联想并清理上下文。
- 随附 6,364 字节的 CC0 示例预测模型，默认最多 5 项／连续 1 轮，配置硬上限 8 项／2 轮。预测模型不从输入内容训练，普通 Rime 词库学习保持原有行为；模型缺失或损坏时基础输入仍可用。已有 custom 配置不覆盖，第三方方案须自行接入预测组件。
- 保留全拼／九键共享学习库、个人词库和常用短语管理、候选置顶／恢复排序、可选横向滚动、注释及长候选全文阅读。忘词是移除学习记录，不是永久屏蔽；联想不参与置顶或忘词，普通候选反复清理后仍保留未提交输入及排序。保留 Shift 双击锁定与自定义主题动作。

715 项新执行应用 JVM 测试、227 项新执行宿主测试和 384 项原生检查通过；同一原生二进制的独立 384 项复测不叠加覆盖。17 项 build-logic＋6 项 compatibility 缓存结果单列。Debug／Release Lint 0 问题，构建和双 ABI Release 签名警告 0。

Android 5.0 和 Android 15 x86_64 模拟器均通过 9.13→9.14 Release 学习数据覆盖升级、三次便携备份、Release／Debug 各 30 项 T11、正式版两主题各 3 项真实点击检查，以及 T10／隐私／T08／编辑器回归，包含快速输入 40 轮和显示隐藏 100 次。GUI 验收前备份范围内的配置、文件元数据及输入法选择已恢复，驱动与拥有的模拟器正常退出。

两轮 3,903／8,198 条原始 W/E/F 及完整控制台诊断保留，平台警告和环境风险未全部消除。API35 一次性 Debug WebView Renderer code -1 与测试主动销毁时序相关，因果关系未证明；不宣称所有平台崩溃为零。旧 API21 坏 SD 环境已退休并保留，新 SDK SD 的 FSInfo 修复及文件系统检查通过，完整历史见验收记录。
