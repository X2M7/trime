## 这一项解决什么

把九键方案、两套内置主题、Rime 原生消歧、拼音选择控件与提交接线一起交付。用户可在现有方案选择器启用 `luna_pinyin_t9`，部署后输入数字、筛选拼音、选择汉字。单独提交一个原生方法或一组布局还不能完成这条输入路径，因此本项按完整行为组织，不再拆成逐行 PR。

操作约定以源码中的 [doc/t9-input.md](https://github.com/X2M7/trime/blob/contrib/pr-t9-input/doc/t9-input.md) 为准；该链接当前指向工作分支，不表示已验证或已经上游合入。

## 必须一起审阅的范围

- **方案与布局**：新增九键拼音方案，使用现有 `luna_pinyin` 词典及用户词典；两套内置主题提供对应布局。沿用现有方案选择和部署入口，不重设已有用户的方案选择。自定义主题仍须提供相应键盘或 `trime/keyboard` 映射。
- **原生拼音消歧**：维护数字原文、分段、焦点、锁定拼写、撤销和取消；使用原生状态 revision 拒绝过期的拼音操作。内部锁定标记不得出现在预编辑文本或字面提交中。
- **输入栏与协议接线**：独立显示分段与拼音选项，保留现有汉字候选 API 和批量候选响应。每次响应额外读取一份当前拼音状态整快照，不逐候选跨 JNI 查询音节。
- **预编辑与编辑器**：九键预编辑显示实际拼写，携带可映射光标；处理 UTF-16 触摸位置到 UTF-8 原始偏移的一次转换。触摸保存显示内容身份，排队光标任务在输入状态重置时取消；新编辑器或重启编辑器清除上轮拼音锁。延迟 ASCII 提示的原生读取也经现有 Rime 单线程上下文。
- **数字及切页**：2–9 进入拼音；长按数字走字面输入。存在组合时先走完整原始输入 Return 路径，再提交数字。数字页和符号页使用字面模式，回主布局恢复当前方案；英文布局沿用现有布局切换提交行为。
- **聚焦检查与使用说明**：原生状态/映射测试、协议与预编辑 JVM 测试、控件操作绑定和主题资产检查随功能交付。测试是否实际运行、执行数量和平台结果须依冻结源码的原始记录填写。

## 明确不包含

本项不包含下一词联想、隐私模式、候选置顶、可选模糊音设置、通用编辑器代际/候选快照框架、输入延迟统计、首次设置和配置导入、T13 大视口或无障碍改造，也不携带 fork 的包名、签名、版本、Pages 或发布配置。辅助拼写来源字段保留协议形状，当前不启用可选模糊/修复偏好。

它不改变普通汉字候选的既有索引协议，也不宣称修复全部候选刷新/点击交错或一般消息丢弃问题。已有独立小 PR 的修复不因本功能一并宣称完成。
