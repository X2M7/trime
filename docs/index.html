这次改了什么

拼音消歧与纠错

按方案词典列出拼音，可锁定、修改中间音节、解锁和撤销；选择拼音不提交汉字。

自适应九键布局

两个内置主题同步 3x3 主键区和侧边功能键，支持拼音侧栏、窄屏横排、左右单手模式及键高设置。

数字与滑动

长按 2-9 直接输入数字，空格滑动移动光标；长按和滑动不会额外触发普通点击。

测试方式

  1. 先备份配置与词库，再覆盖安装 ARM64 APK。包名及签名延续旧预览版，显示名称不带“调试版”。
  2. 打开任意输入框，切换方案到 `朙月拼音九键` / `luna_pinyin_t9`。
  3. 输入 64426，选择拼音 ni 后保留 426，再选择汉字候选提交。
