这次改了什么

九键方案

新增 `luna_pinyin_t9.schema.yaml`，把 a-z 映射到 2-9，复用朙月拼音词典。

九宫格键盘

在内置 Trime 主题中加入 `luna_pinyin_t9` 键盘，显示 ABC、DEF、GHI 等九键分组。

自动切换布局

切到数字拼音方案时，键盘窗口会优先匹配九键布局，不再停留在 26 键。

测试方式

  1. 安装 release 中的 APK，并在 Android 设置里启用 `Trime (Debug)` 输入法。
  2. 打开任意输入框，切换方案到 `朙月拼音九键` / `luna_pinyin_t9`。
  3. 输入 `64`、`426`、`94264`，观察候选词和九键布局是否正常。
