九键输入与编辑

拼音消歧与纠错

按方案词典列出拼音，可锁定、修改中间音节、解锁和撤销；选择拼音不提交汉字。

自适应九键布局

两个内置主题同步 3x3 主键区和侧边功能键，支持拼音侧栏、窄屏横排、左右单手模式及键高设置。

数字与滑动

长按 2-9 直接输入数字，空格滑动移动光标；长按和滑动不会额外触发普通点击。

安装与使用

  1. 先备份配置与词库，再按设备架构选择 ARM64 或 x86_64 APK。请在版本 Release 页面核对版本与附件，Latest 指向线上稳定版。
  2. 首次使用按向导启用并选用输入法，选择九键／全拼和简繁，然后完成中文试打；新安装无需手工编辑 YAML。
  3. 已有用户可保留当前方案和自定义配置，在常用设置调整布局与外观；高级方案与词库设置仍可进入。

本页列出的版本是当前源码的目标版本。下载入口始终指向线上 Latest；当前目标的版本 Release 页面在发布后可用。发布附件仅包括正式 APK 和完整源码包，GitHub 自动生成的 source zip／tar 也会保留。
